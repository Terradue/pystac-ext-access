# Reference

- [Access fields](fields.md): stored names, Python properties, schema constraints, and nested structures.
- [Python API](api.md): signatures and documentation from the current implementation.

The [Access schema](https://stac-extensions.github.io/access/v0.1.0/schema.json) defines the extension contract. The field reference distinguishes schema validation from wrapper behavior.
